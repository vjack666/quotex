# ADR-003 — Dominio experimental

## Contexto

Sin un dominio explícito, una hipótesis validada en EURUSD REAL podría
promoverse para el Edificio OTC, o una condición de M15 aplicarse en M1.

## Decisión

Toda hipótesis declara dominio (REAL/OTC/Crypto/Índices × timeframes) en
`hypothesis.md` y solo se promueve para ese dominio. La evidencia no transfiere.

## Consecuencias

- Refuerza ADR-002.
- Checklist en `docs/specs.md` (Art. 10) exige declarar dominio validado.
