# ADR-002 — Separación REAL / OTC

## Contexto

El bot opera OTC (cuenta real/demo Quotex), pero los datos históricos masivos
disponibles son EURUSD REAL (HistData/MT5). Mezclar ambos cohortes invalida
cualquier promoción.

## Decisión

- EURUSD REAL = entorno de **descubrimiento** de hipótesis (datos abundantes).
- OTC = entorno de **validación final** (datos recolectados por el propio
  sistema, menor volumen).
- Una hipótesis descubierta en REAL es **candidata**, no evidencia definitiva
  para OTC. La promoción al Edificio requiere validación OTC.

## Consecuencias

- El Art. 10 del Charter prohíbe transferir evidencia entre dominios.
- `hypothesis.md` declara dominio fijo; `validation.md` declara dominio validado.
