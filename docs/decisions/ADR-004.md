# ADR-004 — Parsimonia y Muerte definitiva

## Contexto

El laboratorio puede derivar en modelos monstruosos (overfitting) o en volver
a probar eternamente ideas ya refutadas.

## Decisión

- **Parsimonia (Art. 11)**: entre dos hipótesis con evidencia equivalente, se
  promueve la más simple.
- **Muerte definitiva (Art. 12)**: una hipótesis refutada en 3 datasets
  independientes se archiva definitivamente; solo revive con ADR o SPEC nuevo.

## Consecuencias

- `validation.md` registra dominio y veredicto; el ciclo de vida (Archived)
  cierra la hipótesis.
- Evita investigación repetitiva y modelos innecesariamente complejos.
