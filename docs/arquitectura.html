Pegajosos / traps frecuentes

  • off_hours UTC 21–24: escanea pero NO entra. Config: SESSION_OFF_HOURS_ENABLED + SESSION_AWARENESS_ENABLED.
  • Frenos 24/7: 4 triggers independientes (Massaniello / drawdown / daily guard / off_hours). Para tomar数据 desactivalos.
  • ML “cableada pero muerta” hasta ≥500 trades. scripts/ml_progress.py + ML_COLLECTION_START marcan la campana.
  • Cualquier columna nueva en scan_candidates requiere DDL + _NEW_COLS en black_box_recorder.py.
  • pyquotex WS comparte mailbox; candado en connection.py; timeframes enforce guard.
