# ADR-001 — Corrección FDR/Bonferroni obligatoria

## Contexto

El laboratorio encontró 36 firmas con apariencia de valor; al aplicar control
de comparaciones múltiples (FDR-BH) quedaron 0 promovidas. El error de falsos
positivos ya ocurrió una vez.

## Decisión

Toda evaluación de múltiples hipótesis APLICA corrección FDR-BH (y Bonferroni
como cota conservadora) antes de cualquier promoción. Implementado en
`src/strategy_lab/multiple_comparisons.py` y usado por `promotion_gate.py`.

## Consecuencias

- Ninguna firma se promueve sin p-value ajustado.
- El Art. 9 del Charter institucionaliza esta regla.
